PROJECT STATEMENT

Project Title: Campus Student Record Manager

Course: Programming in Java

1. Introduction
The task of maintaining academic records of students by hand can be extremely tedious and error-prone when dealing with additions, searches, updates, and maintenance of student records. This project proposes a simple computerized system that can maintain student records along with basic operations of adding, displaying, searching, and updating student records with ease through a friendly command-line interface.

2. Proposed Solution
The Campus Student Record Manager is a java-based command-line application that helps manage students’ academic records with ease. The application allows users to add, display, search, update, delete, and sort student records. Additionally, it can calculate average marks and save the records in a CSV file to enable the application to load existing data on start-up.

3. Objectives
• Develop a working application using Java
• Implement Object-Oriented concepts
• Use ArrayList to store multiple student records
• Perform input validation and exception handling

• Demonstrate File Input/Output concept
• Provide a basic command-line interface for managing student records
4. Features
The following are the features to be implemented in the Campus Student Record Manager:

• Student record addition
• Display all the student records
• Search student record by ID

• Update student record
• Delete student record
• Sort student records by name
• Calculate average marks
• Save student records in CSV file
• Load existing student records from CSV file
• Handle invalid user inputs
5. Technologies
The following will be used to develop the application:
Programming Language: Java
JDK: 17 or higher
Interface: Command Line
Data Storage: CSV File
6. Java Concepts
The following Java concepts will be applied in the development of the application:
• Classes and Objects
• Encapsulation
• ArrayList / Collections
• Conditional statements and loops
• Exceptions handling
• File Input/Output
• Sorting
7. Project Modules
The following modules will be developed:
Student.java: This class will be used to hold student data including student ID, name, course, and marks.
StudentRepository.java: This class will be used to manage reading and writing of student records from/to a CSV file.

Main.java: This class will demonstrate the application’s features including the addition of student records, searching, sorting, and deletion of records.
8. Expected Results
The project will produce a working command-line application that can manage student records with ease and demonstrate key concepts of Java programming language.
9. Future Scope
The following future enhancements can be considered:
• Building a Graphical User Interface (GUI) version of the application
• Store records in a relational database using JDBC
• Add login and authentication system
• Generate student performance reports
• Add advanced search and filtering options
• Store additional academic related information
Conclusion
Campus Student Record Manager project demonstrates the practical applications of Java, Object-Oriented Programming (OOP), encapsulation, collections, exceptions handling, sorting, and file input/output concepts.
